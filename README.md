# Proyecto 8: LLM — Tutor Virtual Inteligente

Tutor virtual con NLP (TF-IDF + similitud coseno) que responde preguntas de
estudiantes sobre **programación, matemáticas y ciencia de datos**.

El proyecto completo está en la carpeta **[`tutor_virtual_inteligente/`](tutor_virtual_inteligente/)**.

## Cómo ejecutarlo

```bash
cd tutor_virtual_inteligente

# Windows
python -m venv venv && venv\Scripts\activate
# Linux / Mac
python3 -m venv venv && source venv/bin/activate

pip install -r requirements.txt
python app.py
```

Para la documentación completa (objetivos, tecnologías, ejemplos y la interfaz
web con Streamlit), consulta el
[README del proyecto](tutor_virtual_inteligente/README.md).
